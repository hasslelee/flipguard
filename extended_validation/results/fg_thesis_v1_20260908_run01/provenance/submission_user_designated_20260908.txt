       A CKKS Execution Configuration Selection Scheme for Preserving
        Decision Consistency Between Plaintext and Encrypted Inference
                                                          요 약
   CKKS의 근사 실수 연산에서 발생한 작은 수치 오차가 출력 점수를 임곗값 반대편으로 이동시키거나 클래스
점수의 순서를 바꾸면 최종 판정이 달라질 수 있다. 이러한 판정 변화는 의료·금융·침입 탐지처럼 최종 판정의 유
지가 중요한 암호화 추론 환경에서 특히 중요하다. 본 논문은 평문과 암호화 추론의 판정 일치를 CKKS 실행 구
성 선택 기준으로 사용하는 기법을 제안한다. 초기 구성 68개를 판정 일관성 기준 없이 평가했을 때, 21개 사례에
서 판정 변화 또는 오차 기준 위반이 나타났고 이 중 20개에서는 판정이 달라졌다. 제안 기법은 문제가 없는 사례
에서는 초기 구성을 그대로 채택하고, 문제가 확인된 21개 사례에서만 구성을 한 차례 조정하여 68개 사례 각각의
최종 구성을 확정하였다. 또한 비교 구성 집합을 전체 평가하는 방식보다 암호화 구성 평가 횟수를 83.43% 줄였
으며, 비교 집합에 적합한 구성이 존재한 모든 사례에서 적합한 구성을 선택하였다.




                                                      ABSTRACT
    In CKKS approximate arithmetic, small numerical errors can move scores across decision thresholds or reorder class
scores, changing the final decision. This paper proposes an execution-configuration selection method that derives an initial
configuration from the computation graph and per-input margins, evaluates encrypted outputs, and selects the first
configuration satisfying all criteria. Without using the decision-consistency criteria for configuration acceptance, 21 of the
68 cases exhibited a decision change or an error-limit violation; decision changes occurred in 20 cases. The method
retained unaffected configurations and adjusted only the 21 affected cases, finalizing one acceptable configuration for each
of the 68 cases. Compared with exhaustive evaluation of the comparison set, it reduced encrypted configuration evaluations
by 83.43% while selecting an acceptable configuration in every case where one existed, demonstrating the need to consider
application-level decisions as well as numerical error.

Keywords: CKKS, homomorphic encryption, decision-consistency, execution configuration selection
