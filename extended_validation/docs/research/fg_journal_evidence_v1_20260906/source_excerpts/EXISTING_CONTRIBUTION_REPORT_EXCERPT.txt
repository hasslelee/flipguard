1: # CKKS 판정 조건과 선택 절차의 기여 검증
2: 
3: **판정 조건을 선택에 넣는 추가 효과는 주 A–B 비교에서 미관측이다.** A30과 B30은 14개 사례–선택블록에서 같은 구성을 골랐고 0개에서 달랐다. 독립 후보 지도에서 조건별 수용이 다른 후보는 1개지만, 후보 집합 차이와 실제 제한 선택의 개선은 별개다.
4: 
5: **제안 C가 단순 판정 선택 B보다 적은 후보 평가를 필요로 한다는 효과는 미관측이다.** B30보다 적게 평가한 블록은 0, 같은 블록은 10, 더 평가한 블록은 4개다. C의 선택·추론 비용 효과는 사례와 정확성 요구에 따라 아래 표로 분리하며, 구성 변경 자체를 개선으로 세지 않는다.
6: 
7: **독립 수치 기준의 판정 한계에 대한 판정은 지지됨이며, 확인한 허용값 범위에 한정한다.** 동일 평가 자료에서 주 최대오차 조건을 통과하면서 전체 판정 불일치가 나온 독립 진단 후보는 0, 별도 감사 구성은 0개다. 사전 고정한 허용값 민감도에서 수치 통과와 판정 불일치가 함께 나온 후보–허용값 조합은 1개다. 이것은 실제 A/B 출발점이나 허용값을 바꿔 다시 선택한 결과가 아니다. 스트레스의 주 조건에서 같은 유형은 0개로 별도 집계하며 일반 발생률에 합치지 않는다.
8: 
9: A–B는 수용 조건 교체의 효과, B–C는 같은 판정 목적에서 합성·조정 절차의 효과이다. 아래의 정확성·적용 범위·비용 결과를 함께 판단하며, 현재 범위의 무차이는 모든 조건에서 기여가 없다는 증명이 아니다.
10: 
11: **선택·일반 감사의 통과가 새 입력 전체의 판정 보장은 아니다.** 외부 공통 스트레스에서 C는 적용 영역 판정 변화 1회와 오차 조건 위반 6회가 있었다. 합성 입력의 실제 정답·고객 타당성은 미확정이지만, 고정 모델의 평문 판정과의 불일치는 관측 사실이다. 아래의 동일 입력 비교와 내부 스트레스를 함께 보고한다.

23: 주 비교 B30–C의 선택 구성은 0개 사례–선택블록에서 같고 14개에서 달랐다. 동일 구성 alias는 같은 감사 자료를 공유하므로 역할을 늘려 분모를 부풀리지 않는다.
24: 
25: 독립 후보 지도에서 주 수치 조건을 통과하면서 전체 입력의 판정 불일치가 발생한 후보는 0개이며, 그중 적용 영역 불일치가 있는 후보는 0개다. 이 지도는 실제 제한 선택과 별도인 사후 조건 진단이다. 관측되지 않은 유형을 만들기 위해 허용값·모델·입력을 조정하지 않았다.
26: 
27: A–B의 수용 조건 효과와 B–C의 선택 절차 효과를 합치지 않는다. 표형 네 모델은 주 수치 조건 자체가 적용 영역 오차 조건을 포함한다. 선택 비용 차이가 있어도 판정 불일치 감소의 증거로 대체하지 않는다. 두 키 블록의 시간 차이는 관측값이며 통계적 우월성·동등성 판단은 아니다.

209: 외부 상태: `SCHEDULE_EXHAUSTED_CHECK_FAILURES`. [외부 설계·문헌 범위](EXTERNAL_DESIGN_AND_LITERATURE_KO.md)와 [외부 독립 재집계](EXTERNAL_RESULTS.json)를 따른다. HEDiff는 불일치 탐색 방법이지 구성 선택 경쟁 알고리즘이 아니다. 원래 가중치가 없어 한 고정 seed의 공개 절차 재학습으로 표시한다. 원래 native 두 logit과 같은 실수 다항식의 공통 Lattigo 두 logit 연결을 구분한다.
