# 최종 PDF에 대한 최소 보강 문단안

최종 PDF에는 삽입하지 않은 별도 제안이다. 기존 본문의 수식·장절·용어를 복원하거나 재구성하지 않는다. 보고서/CSV는 재현 부록이고 아래 문단만 본문 수준의 후보로 둔다.

## §5.1–5.2 평가 범위 보강

기존 다중 클래스 제곱 MLP를 유지하면서 Fashion-MNIST와 세 학습 초기값으로 적용 범위를 확대하였다. 공식 학습 자료에서 학습·개발·구성 선택 입력을 분리하였으며, 시험 자료는 선택 완료 후 고정 구성의 별도 평가에 사용하였다. 세 초기값은 하나의 데이터·모델 구조에 대한 반복 사례로 구분하였다. 평가 입력과 키 관측을 따로 집계하고 적용 영역 밖의 판정 변화도 보존하였다.

초기값 0에서는 선택 후보 1개를 평가하였고, 별도 완료 입력 10,000개 중 적용 입력 9999개에서 판정 변화 0회와 입력별 오차 조건 위반 0회를 관측하였다. 경계 영역 판정 변화는 0회였다.
초기값 1에서는 선택 후보 1개를 평가하였고, 별도 완료 입력 10,000개 중 적용 입력 9999개에서 판정 변화 0회와 입력별 오차 조건 위반 0회를 관측하였다. 경계 영역 판정 변화는 0회였다.
초기값 2에서는 선택 후보 1개를 평가하였고, 별도 완료 입력 10,000개 중 적용 입력 10000개에서 판정 변화 0회와 입력별 오차 조건 위반 0회를 관측하였다. 경계 영역 판정 변화는 0회였다.

## §5.5 수치 조건과의 비교

동일한 모델과 유한 후보 범위에서 개발 출력으로 미리 정한 수치 오차 기준을 적용하여 구성을 선택하고 제안 수용 조건과 비교하였다. 공통 초기 합성에는 마진 정보가 포함되어 있으므로 이 비교는 후보 범위 안의 수용 조건에 관한 결과다. 전체 후보 평가 후의 최속 선택은 제한된 후보 수에서 최초 수용 구성을 찾는 절차와 예산이 다르며, 구성 선택 비용과 별도 추론 비용을 구분하였다.

평가한 유한 후보에서는 수치 기준과 제안 기준의 수용 집합이 같아 수용 조건 차이에 의한 선택 개선은 관측되지 않았다. 이는 새 데이터에 대한 관측 범위를 보강하지만 수치 기준 대비 일률적 우월성을 뒷받침하지는 않는다.

## §5.7 외부 비교 범위 보강

기존 공통 다항식에서 공식 EVA의 원래 설정에 따른 암호화 실행과 제안 절차의 독립 선택을 비교하였다. 별도 적용 영역 498입력에서 세 키 관측의 판정 변화와 입력별 오차 위반은 양쪽 모두 없었고, EVA의 수치 오차가 더 작았다. 적용 영역 밖에서는 각각 한 입력에서 판정 변화가 관측되었다. 두 경로의 배치와 실행 일정이 달라 시간 차이를 수용 조건만의 효과로 해석하지 않았다.

관련 연구의 정확도 평가와 구성 수용 조건은 구분한다. FHE-Agent의 활성화 고정 설명을 인정하며 입력별 판정 마진을 선택에 반영하는지에 한정하여 차이를 논의한다. 별도 FHE_AGENT_CORRECTION_KO.md는 완료된 선행 문서의 설명 정정이고 최종 PDF의 자동 수정이 아니다.
