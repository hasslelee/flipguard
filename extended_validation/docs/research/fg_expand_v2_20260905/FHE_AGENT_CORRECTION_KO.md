# FHE-Agent 설명의 정정 기록

대상은 완료된 `../fg_expand_v1_20260905/RELATED_WORK_KO.md`의 FHE-Agent 문단이다. 그 문단의 “활성화 변경을 허용”한다는 일반적인 설명은 철회한다. 기존 파일과 최종 PDF는 보존하고 이 정정 기록을 우선 참조한다.

확인 판본은 [arXiv:2511.18653v1](https://arxiv.org/html/2511.18653v1), 2025-11-23 전초본이다. §4.1 LayerProfiler는 backend가 정한 활성화 다항식의 차수·근사오차를 읽으며 다항식 자체를 변경하지 않는다고 설명한다. §4.3도 활성화 다항식을 고정한 제약으로 설명한다. 따라서 **우리 방법은 모델을 고정하지만 FHE-Agent는 활성화를 바꾸므로 다르다**는 차별화 논거를 사용하지 않는다.

다만 같은 v1의 §5.3에는 LeNet에서 활성화 차수 조정을 허용했다는 문구와 conv1 차수를 낮춘다는 예가 있어 설계 절과 일치하지 않는다. 이는 판본 내부의 설명 불일치로 기록한다. §5.3만으로 일반 설계의 고정 조건을 덮어쓰거나, 반대로 해당 문구를 숨기지 않는다. 저자 확인된 실행 가능한 공식 artifact를 이번 제한된 검색에서 확보하지 못했으므로 실제 구현의 어느 동작이 맞는지는 **미확인**이다. 저장소가 전혀 존재하지 않는다는 주장이 아니다.

정정 후 설명: FHE-Agent는 분석·평문 시뮬레이션·소규모 및 전체 암호화 평가를 결합하며 정확도·수치 정밀도·보안 제약을 수용에 사용한다. 설계 절의 활성화 고정 조건을 인정하고, 우리 연구와의 비교는 입력별 판정 일치·마진 연결 오차 조건을 선택 기준으로 사용했는지에 둔다. 별도 입력·새 키를 쓴다는 사실만으로 유일성이나 우월성을 주장하지 않는다.

원문 및 취득 바이트는 `results/fg_expand_v2_20260905_run01/LITERATURE_REUSE.json`에 기존 취득본과 연결했다. PDF 본문에는 이 오류 설명이 그대로 쓰여 있다고 가정하지 않았다. 실제 최종 PDF 4쪽 §2.4는 언어모델과 결정론적 도구를 통한 구성 자동화라는 수준으로 설명하며 활성화 변경 주장을 하지 않는다.
