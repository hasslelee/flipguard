# DeciProtect의 문제 정의와 증명 범위

고정된 평문 기준 f, 입력 X, CKKS 난수 K에서 복호화 출력은 z_hat이다.
목표는 입력의 정답 레이블이 아니라 D(f(X))라는 **명시적인 기준 모델의 결정**이다.
유보를 ⊥로 두고, 운영 규칙 π는 (복호화 출력, 고정 메타데이터)에서 결정 또는 ⊥를 반환한다.
π에 평문 f(X)를 전달하지 않는다.

## 목표

주요 위험은 R_joint=P(π≠⊥ and π≠D(f(X))), 조건부 위험은
R_selective=P(π≠D(f(X)) | π≠⊥), 반환율은 C=P(π≠⊥)이다.
최적화 문제는 R_selective≤ε, C≥κ, 명시된 보안 정책, 메모리/지연 상한 하에서
설정·키 생성·보정·추론·재계산·통신·큐 대기를 포함한 총비용을 최소화하는 것이다.
R_joint만 작게 만들면 항상 유보하는 해가 생기므로 C와 조건부 위험이 필수다.

## 조건부 결정 보존 보조정리

이진 출력의 참값이 [z_hat−q,z_hat+q] 안에 있다고 가정한다. 그 구간 전체가 임곗값
이상이거나 전체가 임곗값보다 작으면 구간 내 모든 값은 같은 결정을 갖는다.
따라서 interval gate가 반환한 판정은 참값의 결정과 일치한다.
임곗값과 같은 값은 양성으로 정의한다. 음성 구간의 상단은 엄격하게 임곗값보다 작아야 한다.

다중 클래스는 각 참 logit이 대응 구간 안에 있다고 가정한다.
한 클래스의 구간 하단이 모든 경쟁 클래스 구간 상단보다 크면 그 클래스는 항상 argmax다.
공통 q라면 관측 top-two gap > 2q로 검사할 수 있다. 동점은 유보한다.

이 보조정리는 구간이 참값을 포함한다는 **가정 아래** 성립한다.
표본에서 얻은 quantile이 모든 미래 CKKS 실행의 오차 상한이라는 증명은 아니다.
관측 오차, 분포하의 확률 보장, 전역 분석적 오차 보증을 구분해야 한다.

## 두 단계의 통계적 의미

저정밀도 단계 또는 고정밀도 재계산 단계에서 잘못된 판정을 반환하는 사건은
해당 단계의 구간이 참값을 놓친 사건에 포함된다. 각 단계에 대해 전체 모집단의
실패 확률이 α_low, α_high 이하라는 정당한 구간 보장이 있으면 union bound로
R_joint≤α_low+α_high가 된다. 이는 조건부 R_selective의 같은 상한을 뜻하지 않는다.
조건부 위험은 coverage를 함께 고려하거나 독립 감사에서 직접 검정한다.
재계산용 구간은 선택된 어려운 부분집합에서만 성능이 같다고 가정하지 않는다.

파일럿의 packed slot과 반복 키는 교환 가능성·독립성의 증명을 제공하지 않는다.
따라서 DP_PILOT_V1A는 5%라는 설정값을 **보장된 위험**으로 출력하지 않는다.

## 독립 위험 감사

π와 입력 모집단을 먼저 동결한다. 매 trial마다 모집단에서 복원 추출하고 새 키와
새 암호화 난수를 생성한다. 각 trial은 하나의 Bernoulli 결과를 만든다.
실패 k, 시행 n에서 단측 상한은 Beta^{-1}(1−α;k+1,n−k), k=0이면
1−α^(1/n)이다. 두 주장에는 각각 α=0.025를 배정해 가족 신뢰수준 95%를 사용한다.
독립 시행 0개, 전부 실패, 판정 반환 0개는 승인하지 않는다.

이는 고정한 유한 모집단에 대한 정확한 검정 구조다. 배포 분포 전체나 암호키 이외의
인프라 변화로 일반화하려면 별도 설계가 필요하다. 절대적인 무반전 증명이 아니다.

## 재계산의 비용 함정

SIMD 배치에서 한 입력만 남아도 모델 폭·환 차수에 해당하는 ciphertext 계산은 유지될 수 있다.
독립적인 요청별 재시도 확률 p, 배치 크기 b라는 단순 모형을 가정하면 즉시 재계산의
기대 배치 비용은 C_low + [1−(1−p)^b] C_high이다.
따라서 C_low < (1−p)^b C_high인 영역에서만 고정 고정밀도보다 유리할 수 있다.
이는 비용 설명 모형이며 실제 데이터의 독립성이나 지연시간 보장이 아니다.

후속 정책은 모델·키 영역별로 재계산 요청을 모으거나, 배치별로 처음부터 높은 정밀도를
선택하는 방식과 비교해야 한다. 요청을 모을 때의 대기시간, 최악 지연, 키 재사용 및
서로 다른 사용자 키를 섞을 수 없다는 제약을 비용에 포함한다. 현재 naive cascade의
음성 결과를 삭제하지 않고 이 문제를 다음 기여의 검정 대상으로 둔다.

## 위협 모델과 모델 품질

클라이언트가 비밀키를 보유하고 서버는 정직하게 암호화 계산을 수행한다고 가정한다.
이 시스템은 서버의 악의적인 출력 조작을 증명하거나 탐지하지 않는다.
재계산 여부가 서버에 노출되면 점수의 경계 근접성에 관한 정보가 될 수 있으므로
위협 모델에 명시하고, 필요한 경우 고정 스케줄·패딩 비용을 비교한다.
복호화된 원시 CKKS 값을 서버에 돌려주는 프로토콜은 사용하지 않는다.

모델 오류, 비다항식→다항식 변환 오류, CKKS 수치 오류는 서로 다른 손실이다.
현재 파일럿은 직접 학습한 선형/square 모델을 기준으로 한다. 더 큰 모델의 변환은
변환 전후 일치율과 레이블 품질을 독립적으로 통과한 뒤에만 암호화 비교에 넣는다.

## 추가 가설: logit 공통 오차를 제거한 판정 오차

다중 클래스에서 모든 logit에 같은 오차가 더해지면 argmax는 바뀌지 않는다.
따라서 절대 logit 오차의 최대값 대신 `max(error)−min(error)`를 구하면
모든 클래스 쌍의 오차 차이 절대값을 동시에 상계할 수 있다. 이 값이 q_gap 이하이고
관측 top-two gap이 q_gap보다 크면 관측 winner는 평문 winner와 같다.
공통 offset은 이 residual에서 정확히 상쇄된다. K=1인 이진 scalar에는 적용하지 않는다.

이는 판정 차이를 직접 보정하는 후속 가설이며, 클래스 공통 오차의 상쇄나
구간에 근거한 argmax 조건 자체를 새로운 수학으로 주장하지 않는다.
DP_GAP_DIAGNOSTIC_V1에서 이미 노출된 여섯 MLP 사례의 logit을 재사용했다.
공통 오차 반례에 대한 단위 테스트는 통과했지만, 실제 파일럿에서는 추가 반환된
관측이 0개였다. 현재 자료에서 개선이 입증되지 않았으므로 별도 다중 클래스 자료와
새 감사 없이 기여로 승격하지 않는다. 기존 600회 감사의 위험 보장도 이 새 규칙에
이전되지 않는다.

위 보조정리들은 실수 구간 모형에서의 조건부 논리다. 부동소수점 구현에서
기계적으로 증명된 상한을 주장하려면 계산 구간의 outward rounding과 CKKS
오차 상한 자체를 추가 검증해야 한다. 현재 경험적 구간으로 이를 대체하지 않는다.
