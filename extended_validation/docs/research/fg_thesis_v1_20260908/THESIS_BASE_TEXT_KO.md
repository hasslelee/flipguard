# 평문·암호화 추론 간 판정 일관성을 위한 CKKS 실행 구성 선택

석사학위논문 구조화 초안. 학교 양식에 맞춘 제출본은 아니며, 학회 원고의 게재 확정을 의미하지 않는다. 학회 원고의 내용 기준은 사용자가 지정한 2026년 9월 8일 투고본이다. 아래 기존 결과와 이번 후속 결과는 서로 다른 평가로 구분한다.

## 제1장 문제와 연구 목적

### 1.1 연구 배경

동형암호는 데이터를 복호화하지 않고 계산할 수 있게 한다. CKKS는 실수와 복소수의 근사 연산을 지원하므로 기계학습 추론에 활용할 수 있다. 그러나 암호화 계산의 출력은 평문 출력과 정확히 같지 않다. 이 차이가 작은 수치 오차에 그치기도 하지만, 점수가 임곗값을 넘거나 클래스 순서가 바뀌면 최종 판정이 달라진다. 민감한 자료를 사용하는 응용에서는 데이터의 비밀성뿐 아니라 원래 모델이 내린 판정을 유지하는지도 확인해야 한다.

평문 점수가 0.5001이고 양성 판정의 임곗값이 0.5인 경우를 생각할 수 있다. 암호화 결과가 0.4999이면 절대오차는 0.0002이지만 판정은 바뀐다. 반대로 임곗값에서 멀리 떨어진 점수는 이보다 큰 오차에도 같은 판정을 유지할 수 있다. 따라서 출력 오차의 크기만으로 모든 입력의 판정 안정성을 같은 방식으로 설명하기 어렵다. 다중 클래스에서도 최고 점수와 경쟁 클래스의 점수 차이를 함께 보아야 한다.

높은 정밀도를 일괄 적용하면 이런 문제를 줄일 수 있으나 더 큰 모듈러스나 환 차수가 필요해질 수 있다. 환 차수가 증가하면 암호문과 키의 크기, 인코딩과 동형연산 비용도 늘어난다. 반대로 스케일의 비트 수를 줄였다는 사실만으로 실행이 빨라지는 것은 아니다. 같은 환 차수와 같은 소수 개수를 사용하는 구현에서는 저장 배열과 연산 횟수가 유지될 수 있다. 본 연구는 이러한 판정과 비용의 관계를 고정 모델의 실행 구성 선택 문제로 다룬다.

### 1.2 목적과 연구 질문

연구의 입력은 고정된 평문 모델의 계산 그래프, 판정 규칙, 구성 선택용 입력이다. 출력은 사전에 정한 조건을 통과한 CKKS 실행 구성 또는 정해진 평가 상한 안에서 구성을 선택하지 못했다는 결과다. 선택은 오프라인에서 수행하고, 선택된 구성을 고정한 뒤 별도 입력에서 다시 평가한다. 운영 중에 평문 정답을 조회하는 재계산 서비스나 실시간 위험 제어를 제안하는 연구가 아니다.

첫째, 입력별 판정 마진에 연결된 오차 조건이 어느 입력 범위에서 유지되고, 어떤 설정과 선택 자료에서 그 범위가 좁아지는지 확인한다. 둘째, 같은 큰 계산 구조 안에서 정밀도 여유를 사용하는 기존 선택 옵션이 원래 방법을 보강하는지 검토한다. 이때 단순한 판정 기준 선택 방법보다 추가 가치가 있는지를 별도로 묻는다. 셋째, 기존 데이터와 모델의 범위를 벗어난 침입 탐지 자료에 같은 절차를 적용할 수 있는지 제한된 범위에서 검토한다. 실행하지 못한 부분은 결과로 대신하지 않는다.

### 1.3 학회 연구와 학위 확장의 관계

학회 연구는 입력별 판정 조건을 구성 수용에 사용하고, 조건을 통과하지 못한 구성에 정해진 조정을 적용하는 절차를 제시하였다. 학위 확장은 그 절차를 유지하면서 데이터 확대, 독립 대조군, 설정 민감도, 알려진 실패와 비용의 원인을 검토한다. 기존 결과가 보여 준 내부 효과와 외부 수치 기준 대비 추가 효과는 같은 주장이 아니다. 기존 A/B 비교에서 판정 개선이 관측되지 않은 사실과 특정 모델에서 제안 구성이 더 비쌌던 결과를 함께 해석한다.

## 제2장 배경과 관련 연구

### 2.1 CKKS 실행 구성과 비용

CKKS는 입력을 스케일에 따라 인코딩한 뒤 암호화한다. 곱셈은 스케일과 암호문 차수에 영향을 주며, 재선형화와 리스케일은 후속 연산을 위한 형태를 유지한다. 리스케일은 모듈러스 체인의 일부를 사용하므로 계산 깊이가 늘어나면 필요한 소수 개수도 증가한다. 본 연구는 환 차수 N, 암호문 모듈러스 Q, 보조 모듈러스 P, 기본 스케일을 실행 구성의 주요 요소로 사용한다. 슬롯 배치와 회전 계획은 고정 그래프의 실행 요구사항으로 함께 확인한다.

보안 적합성은 비밀키·오차 분포를 고정한 기존 128비트 목표의 파라미터 정책으로 검사한다. 암호문 Q와 평가키 QP를 모두 확인한다. 선언한 소수 비트 수뿐 아니라 실제 생성한 소수의 크기와 라이브러리 유효성도 구분한다. 이러한 정책 수용 검사는 해당 키에 대한 새로운 공격 비용 추정이나 악의적 서버의 무결성 증명이 아니다.

비용은 구성 선택 전체 비용과 선택 후 반복 추론 비용으로 나뉜다. 추론 비용은 입력 인코딩·암호화, 동형연산, 복호화·디코딩의 합으로 정의한다. 파라미터와 키 준비는 별도로 기록하며 전체 호출 비용을 제시할 때 같은 기준으로 포함한다. 직렬화한 자료 크기는 통신량을 이해하는 데 도움이 되지만 실제 네트워크 지연을 측정한 값은 아니다.

### 2.2 수치 정확도, 분류 정확도, 판정 일치

수치 오차는 평문 출력과 암호화 출력의 차이다. 분류 정확도는 예측이 정답 레이블과 일치하는 비율이다. 판정 일치는 같은 입력에서 평문 모델과 암호화 모델이 같은 판정을 내리는지를 뜻한다. 평문 모델이 오분류한 입력도 암호화 추론과 판정이 같을 수 있다. 반대로 두 실행의 전체 분류 정확도가 같아도 서로 다른 입력에서 오분류하면 입력별 판정은 다를 수 있다.

최대 절대오차는 모든 출력의 오차를 상계하지만, RMSE는 평균 제곱오차에 기반한다. RMSE 조건만으로 개별 입력의 오차를 같은 값 이하라고 할 수 없다. 이진 임곗값의 마진과 다중 클래스의 모든 경쟁 점수 차이도 다른 조건이다. 본 연구는 이 구분을 유지하여 수치 조건 통과, 판정 일치, 보수적 오차 조건 통과를 각각 집계한다.

### 2.3 선행 방법과 비교 범위

CHET와 EVA는 계산 그래프와 실행 요구를 바탕으로 암호화 계산을 구성하는 기반을 제공한다. HECATE와 ELASM은 오차와 실행 비용을 함께 고려한다. 특히 오차 기준이나 분류 정확도를 평가한 선행연구가 있으므로 기존 연구가 판정을 포함한 정확성을 전혀 고려하지 않았다고 전제할 수 없다. 본 연구가 직접 다루는 차이는 입력별 마진과 실제 판정 일치를 후보 구성의 수용 조건으로 연결한다는 점이다. 이러한 조건의 차이가 실제 선택 차이를 만드는지는 별도 실험이 필요하다.

Orion은 신경망의 암호화 실행 계획과 다양한 모델의 평가를 다루며, FHE-Agent는 구성 생성과 분석·평가를 결합한다. 기존에 검토한 FHE-Agent 판본의 §4.1과 §4.3은 활성화 다항식을 고정한다. 이를 활성화 변경을 허용하는 방법으로 설명했던 초기 검토 문구는 후속 정정 기록에 따라 사용하지 않는다. 같은 판본 §5.3에는 활성화 차수 조정 예가 있어 설계 절과의 설명 불일치도 남아 있으며 실제 구현의 어느 동작이 맞는지는 미확인이다. 논문 본문에 어떤 조건이 명시되지 않았다는 사실을 공식 구현에 그 기능이 없다는 증명으로 취급하지 않는다.

HEDiff는 암호화 추론에서 판정 이탈을 찾는 문제와 관련된다. 판정 이탈 탐색의 입력 생성과 본 연구의 실행 구성 선택은 서로 다른 절차다. 공개 절차를 이용해 만든 모델과 원 저자가 사용한 가중치·자료 전체의 재현도 구분한다. 외부 산출 파라미터를 공통 백엔드에 이식한 경우에는 실행 일정·스케일 관리·슬롯 배치까지 같다고 가정하지 않는다.

기존 외부 비교에서는 공식 EVA/SEAL 실행, HEIR 공개 설정의 Lattigo 이식, HEDiff Bank 절차의 실행 범위를 각각 기록하였다. 학회 원고의 EVA 입력 스케일20 실험에서 관측된 판정 이탈을 EVA의 모든 선택 절차에 대한 실패로 일반화하지 않는다. 이후 다른 공식 설정의 비교에서 양쪽이 같은 판정을 유지한 결과도 보존한다. 자세한 판본과 실행 수준은 문헌 및 증거 대응표에 연결한다.

## 제3장 문제 정의와 선택 조건

### 3.1 입력별 충분조건

이진 판정에서 평문 점수 f(x), 임곗값 τ에 대해 마진은 γ(x)=|f(x)−τ|이다. 해당 실행의 절대오차가 마진보다 작으면 점수가 임곗값을 넘어갈 수 없다. 실제 수용에서는 미리 정한 0<ρ<1을 사용하여 오차가 ργ(x)보다 엄격히 작은지를 검사한다. 또한 실제 평문·암호화 판정도 직접 대조한다. 이 조건은 유한하고 정상적인 출력에 적용한다.

다중 클래스에서는 평문 승자 i와 모든 다른 클래스 j에 대해 두 출력 절대오차의 합이 ρ(z_i−z_j)보다 작은지를 검사한다. 최고 두 점수의 차이는 적용 영역을 정하는 데 사용하지만, 수용 검사는 두 클래스만으로 제한하지 않는다. 점수가 동점인 입력은 δ=0에서도 경계에 속한다.

구성 선택용 집합 중 마진이 δ보다 큰 입력을 적용 영역으로 정의한다. 원래 설정은 ρ=0.5, δ=0.001이다. 이는 실험 전에 고정한 운용 값이며 이론적 최적값이라는 주장은 하지 않는다. 적용 영역이 비어 있으면 해당 구성의 적합성을 선언하지 않는다. 경계 입력의 판정과 오차도 별도로 기록하되 적용 영역의 성공률에 섞지 않는다.

### 3.2 관측과 보장의 범위

충분조건의 성립은 해당 입력과 해당 실행에서 판정을 보존한다. 그러나 선택 입력과 몇 개의 키에서 그 조건을 통과했다는 관측은 모든 미래 입력·키에서도 조건이 성립한다는 뜻이 아니다. 선택에 사용하지 않은 입력에서 재평가하는 이유는 이 차이를 확인하기 위해서다. 미리 관측한 입력의 재평가는 새 입력 일반화 실험이라고 부르지 않는다.

키 반복은 암호화 오차의 변동을 관측하는 단위다. 같은 입력에 여러 키를 적용한 사건 수와 고유 입력 수를 함께 제시한다. 한 암호문에 많은 슬롯을 사용하거나 같은 키를 반복 사용한 횟수를 독립 표본 수로 계산하지 않는다. 별도 모집단과 표집 모형을 정하지 않은 0회 관측으로 위험 상한을 새로 선언하지 않는다.

### 3.3 수치 기준과 판정 기준의 관계

동일한 이진 출력 자료에서 최대 절대오차 허용값이 ρδ보다 작으면, 그 수치 조건을 통과한 후보는 적용 영역의 판정 오차 조건도 통과한다. 전체 출력의 오차 상계가 적용 영역의 각 입력 오차를 이미 제한하기 때문이다. 이 경우 판정 조건을 추가해도 선택이 바뀌지 않을 수 있다. 이는 수치 기준의 실패를 만들도록 허용값을 조정할 이유가 아니다.

다중 클래스에서는 두 출력 오차의 합이 필요하므로 같은 최대오차 허용값의 두 배를 고려해야 한다. RMSE에서는 개별 오차를 얻기 위한 별도 상계와 출력 수가 필요하다. 따라서 이진 최대오차의 포함 관계를 다른 지표와 모델에 그대로 적용하지 않는다. 후보의 수용 집합이 달라도 탐색이 첫 후보에서 종료되면 실제 선택은 같을 수 있다.

## 제4장 실행 구성 선택 절차

### 4.1 초기 합성과 실제 수용

기존 방법 C는 고정 그래프에서 연산 종류, 곱셈 깊이, 필요한 슬롯과 회전 등의 실행 요구를 얻는다. 선택 입력의 평문 출력과 마진을 이용해 오차 예산을 만들고, 중간 수치 범위와 민감도를 반영해 초기 정밀도를 추정한다. 이 추정은 실제 암호화 오차에 대한 분석적 보증이 아니다. 실제 소수 생성과 백엔드 유효성 검사에서 초기 스케일이 조정될 수 있다.

생성한 구성은 Q와 QP의 보안 기준을 검사한 뒤 선택 입력 전체에서 실행한다. 각 후보는 독립적으로 생성한 세 키 문맥에서 평가한다. 계산 완료, 보안 적합성, 적용 영역의 판정 일치와 입력별 오차 조건을 모두 만족한 첫 구성을 선택한다. 선택이 끝난 뒤 더 빠른 후보를 추가로 탐색하지 않는다.

정밀도 부족으로 수용되지 않으면 스케일 지수를 4비트 높이는 기존 조정을 적용한다. 연산 단계가 부족하면 Q 소수 한 개를 추가하는 조정을 사용한다. 초기 평가를 포함한 상한은 네 구성 평가다. 상한 안에서 적합한 구성을 얻지 못하면 부적합한 구성을 최종 결과로 반환하지 않는다. 이런 미선택은 실행 중 서비스의 유보율을 뜻하지 않는다.

### 4.2 대조군과 유한 비교

학회 연구의 내부 대조는 같은 초기 합성을 사용하면서 판정 일치와 입력별 오차 검사를 함께 제거한다. 초기 합성에는 마진 정보가 남아 있으므로 이를 완전히 판정 정보와 독립적인 기존 방법이라고 부르지 않는다. 유한 비교 집합도 같은 초기 합성의 오차 예산을 공유한다. 전체 CKKS 공간의 최적해를 탐색한 결과가 아니다.

후속 A/B 비교는 마진에 의존하지 않는 동일 후보 생성기와 동일 시작점·진행 순서를 사용한다. A는 개발 자료에서 고정한 수치 조건을, B는 판정 관련 수용 조건을 사용한다. B가 수용 검사에서 마진을 사용하는 것은 의도된 설계이며 후보 생성의 독립성과 모순되지 않는다. B와 C는 같은 판정 목적 아래 다른 초기 구성과 선택 절차의 효과를 비교한다. 더 엄격한 수치 목표까지 항상 같은지는 따로 확인한다.

### 4.3 설정 민감도와 제한된 옵션 검증의 위치

이번 후속 평가에서는 ρ, δ 또는 선택 입력 수를 한 번에 정한 유한 격자로 바꾼다. 기존 출력을 다시 분류하는 분석과 실제로 구성을 다시 선택하는 실험을 구분한다. δ를 높여 실패 입력이 적용 영역에서 빠졌다는 사실만으로 판정이 개선됐다고 하지 않는다.

정밀도 여유 옵션은 원래 소스에 있으나 기본 경로에서는 비활성 상태였던 기능이다. 이를 별도 C′로 연결하여 첫 암호화 평가 전에만 적용한다. 같은 N뿐 아니라 Q/P 개수, 실행 경로, 요구 레벨, 슬롯 배치와 회전 요구가 유지됐는지 검사한다. 기존 C와 실패 후 조정은 보존한다. 이 옵션은 이미 선택한 큰 N을 작은 N으로 줄이는 탐색을 하지 않는다. 구체적인 채택 판단은 실제 비교 결과에 따르며, 옵션의 존재 자체를 새 알고리즘의 기여로 세지 않는다.

### 5.2 학회 주요 결과와 한계

주요68사례에서 초기 구성은 모두 계산을 완료했다. 이 중20사례에서는 판정 변화와 오차 조건 위반이 함께 나타났고, 한 사례에서는 판정은 같지만 오차 조건을 위반했다. 나머지47사례는 두 조건을 모두 만족했다. 제안 절차는 문제가 관측된21사례에서 스케일을 한 차례 조정했고, 그 뒤 선택 입력의 기준을 모두 만족했다. 이때 Q 소수 개수와 N은 바뀌지 않았다.

구성 선택에 사용한 실제 암호화 후보 평가는89회였고, 미리 정한 비교 집합의 전체 평가는537회였다. 해당 유한 비교에서 평가 횟수 감소율은83.43%였다. 적합한 후보가 존재한68사례에서 모두 적합한 구성을 선택했으며,65사례에서는 유한 집합의 가장 빠른 수용 구성과 실제 파라미터·경로가 같았다. 수용 조건을 무시한 최속 실행 구성은18사례에서 판정 또는 오차 조건을 위반했다. 두 최속 기준은 서로 다른 질문에 답한다.

별도 입력 평가의68/68 통과는 사례별 결과다. 적용 영역의16,049 사례–입력에서 세 키 반복의 판정과 오차 조건이 유지됐다는 범위를 갖는다. 경계2,318 사례–입력에서는 키 반복을 합한 판정 변화21회가 있었다. 추가63모델 분석에서도 Banknote 모델의 한 별도 입력·한 키에서 판정은 같지만 오차 조건을 위반한 사례가 있었다. 따라서 주요 적용 영역의0회만으로 모든 입력의 성공을 결론 내릴 수 없다.

대응 추론 시간은 사례 내부의 기하평균과16개 데이터셋–모델 조합을 같은 비중으로 반영하여 집계하였다. 기준 구성/제안 구성 비율은1.00054였다. 이는 정해진 후보와 측정 환경의 관측이며, 전체 선택 비용을 포함한 서비스 전체 지연이나 모든 구성 공간의 최소 지연을 뜻하지 않는다.

### 5.3 데이터 확대와 모델 품질

첫 확대의 네 모델에서는 별도1,024 사례–입력 중 적용 영역820개에서 선택 구성의 판정 변화와 오차 조건 위반이 관측되지 않았다. 초기 구성에서는 적용 영역의 키 합산 판정 변화201회가 있었다. 이201→0은 우리 초기 구성과 선택 구성의 내부 비교이며 특정 외부 방법의 실패 수가 아니다. 경계 입력에서는 선택 구성의 판정 변화 한 회가 관측됐다.

Spambase MLP의 별도 적용 영역은75/256, 약29.3%였다. 전체 입력을 분모로 보면 이 모델의 판정 보호 평가 범위는 좁다. 평문 정확도와 판정 보호 범위도 같지 않다. 같은 확대의 평문 별도 정확도는 Spambase 선형91.80%, MLP90.62%, HTRU2 선형98.05%, MLP97.66%였다. 높은 정답률이나 낮은 암호화 오차 하나로 다른 지표를 대신하지 않는다.

Fashion-MNIST에서는784→100→10 제곱 활성화 모델 세 개를 고정하고 공식 시험10,000개를 각 모델에서 평가했다. 적용 입력 수는 초기값0과1에서각9,999개, 초기값2에서10,000개였다. 기존 선택 구성의 적용 영역에서 판정 변화와 오차 조건 위반은 관측되지 않았다. 세 평문 모델의 시험 정확도는87.66%,87.62%,87.88%였고, 어려운 클래스의 재현율은 이보다 낮았다. 판정 일치는 이러한 모델 품질의 한계를 고치지 않는다.

Fashion 실행은 특징별 암호문784개에 여러 입력을 슬롯으로 배치하고 출력 암호문10개를 만든다. 표형 확대에서는 한 입력의 각 특징을 슬롯에 반복한 암호문을 사용하므로 한 호출의 독립 유효 입력은 하나다. 배치의 입력 수와 암호문 수를 혼동하지 않는다. 서로 다른 packing의 배치 시간과 입력당 시간을 직접 같은 단위로 비교하지 않는다.

### 5.4 독립 대조군에서 확인한 무차이와 비용

일곱 모델과 두 선택 키 블록에서 A30과 B30은 모두 첫 후보를 수용하여 같은 구성을 선택했다. 네 이진 표형 모델의 최대오차 허용값은 ρδ보다 작아, 동일 출력에 대한 A 통과가 적용 영역의 B 조건을 포함했다. Fashion에서는 이런 포함 관계가 없었지만 실제 오차가 충분히 작았다. 관측하지 않은 후보까지 두 수용 집합이 같다고 결론 내리지 않는다.

기존 B–C 비교의 표형 네 모델에서는 C가 더 작은 N을 사용해 추론 비용이 낮았다. 그러나 일부 C 구성은 A가 요구한 더 엄격한 수치 기준을 통과하지 못했다. 이는 동일 수치 정확성에서의 속도 개선과 구별해야 한다. 같은 판정 목적 아래의 비용 차이는 관측됐지만, A/B 대비 추가 판정 개선이 있었다고 바꿔 쓸 수 없다.

Fashion 초기값0에서는 C의 정밀도 추정이 스케일33을 요구했다. QP의 선언 합218비트가 N8192의 기존 한도214비트를 넘어 N16384가 선택됐다. B30은 같은 판정 조건을 만족하면서 N8192를 사용했다. 더 큰 N으로 인한 C의 비용 손해는 기존 증거에서 확인되며, 보안 한도에서 P를 빼거나 수용 뒤 더 작은 N으로 소급 교체하여 제거하지 않는다.

### 5.5 Bank 실패를 통해 확인한 검증 범위

Bank는 공개 절차로 이미 학습한20→256→2 고정 모델을 사용한다. 공통 Lattigo 비교에서는 활성화 t²+t를 이동된 제곱으로 계산하는 기존 어댑터를 유지한다. 실수 계산식은 같지만 원래 float32 출력과 공통 float64 출력의 차이는 별도로 평가하며, 이를 암호화 오차 하나로 합치지 않는다. 이번 새 비교가 공식 TenSEAL 실행을 다시 수행한 결과는 아니다.

Bank의 기존 선택16개는 최소 마진이 약1.05585였고, 합성 스트레스의 최소 마진은 약0.01170이었다. 원래 C는 스케일20, N8192, Q5/P1을 선택했다. 선택 입력은 통과했지만 노출 합성16개에서 키 합산 판정 변화 한 회와 오차 조건 위반 여섯 회가 있었다. 실패 입력에서는 두 클래스의 반대 방향 출력 오차가 평문 점수 차이를 넘었다. 오차 충분조건 자체가 성립한 상태에서 판정이 뒤집힌 반례는 아니었다.

실패 입력의 전체 중간값 최대가 선택 입력보다 크지는 않았다. 작은 마진, 출력 오차의 방향, 입력·은닉 유닛별 범위가 함께 관련되며, 기존 최종 출력 자료만으로 각 암호화 연산 단계의 오차 기여를 분리할 수 없었다. 따라서 작은 마진 하나로 근본 원인을 확정하지 않는다.

Bank의 B30과 C는 N과 소수 개수, 실행 경로가 같았다. 스케일을 줄여도 가중합과 제곱 연산 수, RNS 배열 크기가 줄지 않아 기존 시간 이득은 거의 없었다. 이 관측은 같은 큰 계산 구조에서 정밀도 여유를 사용할 근거가 되었으나, 이미 성공한 B보다 새로운 가치가 있음을 뜻하지는 않았다. 합성 입력의 실제 고객 입력으로서의 타당성과 정답은 미확정이므로 원본 고객 발생률과 합치지 않는다.
