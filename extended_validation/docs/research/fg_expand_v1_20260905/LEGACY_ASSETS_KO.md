# 기존 평가 자산과 실제 공백

`LEGACY_INVENTORY.json`·`LEGACY_CASES.csv`는 주요 68개와 추가 모델 63개를 실제 선택/별도 평가 파일·모델 hash·분할·키·packing에 연결한다. 원시 자료를 읽기만 했으며 그 코드나 인터프리터를 원본에서 실행하지 않았다. `LEGACY_SOURCE_BINDINGS.json`은 이 목록을 만들 때 읽은 한정된 파일만 결속한다. archive 전수 해시는 반복하지 않았다.

각 선택 후보는 원래 3개 새 키로 실행한다. 표형은 한 행씩 스칼라 복제 암호문, 큰 다중 클래스는 특징별 암호문에 여러 sample slot, 공간 CNN은 한 이미지의 공간 slot이다. 슬롯 수·동일 키의 반복·시간 예열과 측정 pass를 독립 입력으로 세지 않는다. 주요 시간 실험은 예열1 제외·측정6·키3이며 65표형은 행 단위, 큰 세 모델은 20입력 묶음 단위이다.

범위가 두터운 축은 다섯 자료의 표형 분할 반복과 작은 square 모델이다. 얇은 축은 새로운 분포의 영상, 큰 모델의 여러 분할, 더 많은 별도 입력에서의 적용 영역/오차, 독립 하드웨어다. WDBC 2층 MLP 한 사례는 선택 20/114·별도 23/113만 적용 영역이었다. 성공 사례 수만으로 이 차이를 숨길 수 없다. 기존 68개 모든 사례의 적용 영역이 비어 있지 않았다는 사실과 전체 입력 보장은 다르다.

## 본문에 모두 넣지 않은 자산

기존 V18은 새로운 암호화 실행 0회인 재분석이다. 동일 유한 후보의 최소 오차 목적·Pareto 진단, 초기 판정/오차 조건 동시 제거, 초기만 허용하는 비교도 이미 있다. 다시 처음 개발한 아이디어로 세지 않는다. 초기 탈락 21개는 별도 입력에서 **미평가**였고 실패 21개가 아니다. 이것이 신규 초기 구성 감사의 근거다.

외부 비교 V8의 raw CSV 존재·행 수와 현재 결속을 `OTHER_ASSETS.json`에 기록했다. HEIR의 공통 다항식 500입력·3키 결과는 존재하지만 대응 시간의 direct arm에 오류가 있어 기존 시간 우월성은 차단되었다. EVA는 같은 출력 의미의 비교이지 SEAL와 Lattigo의 무조건 동일 시간 비교가 아니다. HECATE/ELASM 관련 CoreLab은 36+36계획 중 70계획의 200입력, 14,000행 수치 자료와 2개 실패를 남겼다. 판정 출력 계약이 맞지 않아 70개의 판정 보존 사례로 세지 않는다. 원시 테이블의 현재 존재를 확인했으며 전체 과거 실험을 새로 재현한 것은 아니다.

V17의 이전 2-vCPU 부분 결과는 최종 6-vCPU 결과와 환경이 달라 보존만 된 자료다. 기존 구현의 Harris/Sobel·분석적 bound·외부 adapter 등 지원/연구 코드가 존재한다는 사실도 곧 새 최종 논문의 검증 사례라는 뜻은 아니다. 최초 `docs/review/WORKSPACE_INVENTORY.json`의 전체 파일 목록 요약을 재사용했고 제3자 빌드 환경의 모든 줄을 의미적으로 재심사했다고 하지 않는다.

## 최근 DeciProtect 결과의 분리

`OTHER_ASSETS.json`의 12개 파일럿은 Spambase/Wine × 선형/MLP12 × seed20260905–07이다. Spambase의 중복 처리 후 4,204행은 split마다 학습2,102·개발630·보정630·test842, Wine178행은 89/26/27/36이다. seed마다 분할도 바뀌어 순수 학습 초기값 실험이 아니다. 6개 MLP 모두 실제 학습 기록의 200회 L-BFGS 한도·converged=false를 확인했다.

이 파일럿은 고정 정밀도·구간 gate·cascade의 다른 방법이다. 모델의 출력은 2개/3개 logit이어서 이번 기존 스칼라 출력 모델로 의미를 바꾸어 재사용하지 않았다. 데이터 로딩·중복 처리 원칙은 재사용할 수 있다. Wine의 표본 부족 유보를 기존 offline 선택의 실패라고 간주하지 않는다. Spambase는 이미 결과를 본 자료이며 새 봉인 모집단으로 표현하지 않는다.

이외 초기 낮은 scale의 정적 prime 생성 실패 6건, stress4조건, gap 진단6조건, 유한 모집단 IID600회, DP-03 비용216개 대조 시행·247native호출은 각각 기존 protocol 결과로 보존한다. 신규 4개 구성 선택 사례나 독립 입력 수에 합산하지 않는다. 해당 위험 상한·반환율·비용 정의도 이전하지 않는다.

PDF 7쪽의 “63개”와 깊이 조건 분류의 표현 문제는 `PDF_METHOD_MAP_KO.md`에 별도 보고했다. 이 문제를 해결했다며 동결 표나 완료 보고서를 수정하지 않았다.
