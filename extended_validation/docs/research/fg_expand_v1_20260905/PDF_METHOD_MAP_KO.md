## 구현에서 추가로 확인한 사항

이 절은 재현 자료이며 PDF의 설명을 임의로 확장한 원고 문단이 아니다. 모든 경로는 새 복사본 `research/selection_extension/` 기준이다.

- `internal/ckksplanner/tabular_materialize.go::MaterializeTabularValidationWithOptions`는 raw 특징과 동결 모델의 전처리를 적용하고 **그 모델의 출력 함수**를 계산한다. `BuildTabularWorkloadContract`가 모델·입력 해시와 그래프·정책을 묶는다.
- `internal/ckksplanner/synthesis.go::Synthesize` → `executor.go::RunAdaptiveTabularAutotuneWithOptions` → `ExecuteTabularCandidateWithOptions`가 기존 선택 경로다. `direct_policy.go`, `security_policy.go`, `v17_candidate_space.go`의 본체는 수정하지 않았다.
- `internal/ckksbackend/tabular_inference.go::RunCKKSTabularInference` → `runTabularTimedInference`가 실제 Lattigo 실행이다. 표형 경로는 한 입력씩, 특징별 암호문에 스칼라를 복제한다. 이번 8/16차원 입력은 각각 8/16개 입력 암호문이다. 32개 선택 입력이나 256개 별도 입력을 한 SIMD 배치로 포장하지 않는다. `required_slots=1`은 독립 샘플 수가 아니다.
- 동일 모델의 새 후보 실행마다 호환되는 파라미터·새 키가 생성된다. 암호화 난수는 라이브러리의 난수원이며 학습 seed로 재현시키지 않는다. scale metadata 수정으로 재계산을 대신하지 않는다.
- 이 실행은 **오프라인 구성 선택 실험**이므로 선택자가 평문 기준 점수를 읽는 것이 원래 방법이다. 운영 중 oracle를 읽는 gate나 요청별 유보 서비스로 해석하지 않는다. 단일 로컬 프로세스가 키 소유·암호화·평가·복호화를 모두 수행하며, 네트워크나 다자간 운영을 구현했다고 하지 않는다.
- `internal/ckksbackend/paired_tabular_latency.go::RunPairedTabularLatency`가 예열·대응 입력·순서·키 문맥과 원시 시간 분해를 기록한다. `setup_ms`는 파라미터/키/실행 환경 준비의 묶음이며 순수 키 생성만의 값이 아니다.
- 새 `cmd/fg-expand-case/main.go`는 위 함수 호출과 체크포인트 저장만 추가했다. 별도 평가 전에 네 역할의 후보를 `FROZEN_SELECTION_ROLES.json`에 기록한다. 같은 후보의 별도 평가를 공유할 때 역할 대응을 남긴다. 선택/유한 탐색의 독립 실행은 공유하지 않는다.
- 정식 유한 비교 집합은 `BuildV17DepthCompleteFiniteSet`이다. 과거 별도 14개 격자 진단은 이번 분모에 추가하지 않았다. 근거: 원래 `docs/evidence/comparison_extension_v18/build_offline_replay_v18.py`의 `finite_fastest(entries, acceptable_only=False)`와 `minimum_error(entries, ...)` 호출.

## 수정하지 않고 보고하는 집계 표현 문제

7쪽 §5.1 마지막 문장은 곱셈 깊이를 늘린 그래프도 “63개 사례”에 속하는 듯하게 읽힌다. 그런데 원시 `run_status.csv`에서 63은 출력부 조합 30 + 표형 학습 seed 24 + 다중 클래스 seed 6 + 공간 슬롯 CNN seed 3이며, 깊이 진단 5행은 별도다. 전체 204작업에는 시간 측정·유한 집합 등도 포함되어 있어 204사례로 셀 수 없다. `LEGACY_INVENTORY.json`은 131개 모델 사례와 5개 깊이 조건을 분리한다.

최소 보완안은 해당 문장에 “추가 모델 사례 63개와 별도의 곱셈 깊이 조건 5개”를 명시하는 것이다. **제안만 남기며 PDF·Table 5·동결 결과를 변경하지 않았다.** 이 표현 정리는 신규 구성 선택 실험과 독립적이다.
