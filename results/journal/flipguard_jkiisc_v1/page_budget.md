# JKIISC Page Budget

The official HWP form has not been converted or edited in this repository, so
the figures below are content-budget estimates rather than rendered page
counts. The target is a 9-11 page general paper, within the official 20-page
hard limit.

| Component | Estimated pages | Compression rule |
|---|---:|---|
| Korean and English abstracts | 0.6 | Keep one result sentence per admitted headline |
| I-II. Introduction and related work | 1.5 | One comparison table; no provider appendix |
| III. Decision-integrity contracts | 1.2 | Binary and multiclass proposition in one figure |
| IV. FlipGuard design | 1.3 | Provider/layer separation as the main figure |
| V. Implementation and methodology | 1.4 | Three-tier hierarchy; provenance details summarized |
| VI. Results | 3.4 | Four core result tables and three result figures |
| VII-VIII. Discussion and conclusion | 1.0 | Limitations tied directly to claim registry |
| References | 0.8 | Twelve primary references |
| **Estimated total** | **11.2 before HWP fitting** | Target 9-11 after official two-column placement |

The first HWP layout pass should reduce repeated protocol prose before reducing
negative-result or security qualifications. Provider interoperability, EVA,
soak-cycle details, and full digest-layer tables stay in the thesis or artifact
appendix. Seven tables and six figures are budgeted; if official placement
exceeds 11 pages, combine Tables 2 and 7 and move Fig. 4 details to its caption.
