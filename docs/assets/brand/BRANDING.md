# FlipGuard Branding

FlipGuard's visual identity joins three ideas in one compact mark: a shield for decision integrity, a split field for synthesis and certification, and opposing arrows with circuit nodes for controlled decision flips in encrypted computation.

## Assets

| Asset | Intended use |
|---|---|
| `flipguard-mark.svg` | Light-background icon |
| `flipguard-mark-dark.svg` | Dark-background icon |
| `flipguard-mark-mono.svg` | Single-color reproduction |
| `flipguard-wordmark.svg` | Light-background README and documents |
| `flipguard-wordmark-dark.svg` | Dark-background README and documents |
| `flipguard-favicon.svg` | Browser and small-icon use |
| `flipguard-social-preview.svg` | Editable 1280 x 640 social preview |

| `flipguard-mark-512.png` | High-resolution raster icon |

## Colors

- Navy `#0D2A52`: integrity and primary structure
- Blue `#1F6FEB`: direct synthesis and active computation
- Cyan `#2F9ECA`: certification and audit signal
- Dark `#0D1117`: dark-background canvas
- White `#FFFFFF`: light-background canvas and contrast

SAFE green is reserved for status graphics and is not part of the logo.

## Usage

Keep clear space around the mark equal to at least one circuit-node diameter. Do not add glow, gradients, 3D effects, shadows, photography, or unverified result and publication claims. The SVGs contain no linked fonts, external resources, or embedded raster data. Run `python3 scripts/build_public_brand_assets.py` to reproduce the generated assets.
