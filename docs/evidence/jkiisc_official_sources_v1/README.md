# JKIISC Official Sources V1

This pack preserves the official KIISC journal guidance, rules, and HWP forms
used for the FlipGuard manuscript contract. The HWP files are stored exactly as
downloaded; they are not converted or rewritten because no authoritative HWP
editing workflow is part of this repository.

The Markdown manuscript is therefore a template-ready content pack, not a
submission-ready HWP or PDF. Author information remains absent from the initial
submission content.

Run:

```bash
python3 docs/evidence/jkiisc_official_sources_v1/verify_jkiisc_official_sources_v1.py
```
