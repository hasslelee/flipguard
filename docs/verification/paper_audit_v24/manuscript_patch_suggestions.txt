[본문 추가]
구성 선택 입력에서는 총 18,385개 중 2,304개(12.5320%)가 결정 마진 0.001 이하의 경계 입력이었고, 나머지 16,081개를 V_delta로 평가하였다. 별도 입력에서는 총 18,367개 중 2,318개(12.6205%)가 경계 입력이었으며 V_delta는 16,049개였다. V_delta가 비어 있는 사례는 구성 선택과 별도 입력 모두 0개였다. SAFE 판정의 판단 반전 및 운용 오차 예산 위반 집계는 V_delta에 한정하고, 경계 입력은 실패가 아니라 V_amb로 별도 보존하였다.

[본문 수정]
별도 입력 전체 재평가와 지연시간 측정의 입력 수를 구분하였다. 65개 tabular 사례의 별도 입력은 각 outer test fold 전체이고 MLP-100과 LeNet-5-small은 각각 500개, packed CNN-lite는 250개이며, 공식 짝지은 지연시간은 각 사례의 별도 입력에서 사전에 고정한 20개 부분집합만 사용하였다.

[통계 방법 추가]
각 사례에서 동일 입력, 키 집합 인덱스와 측정 pass를 유지한 finite-reference/proposed 총 지연시간 비율의 기하평균을 먼저 구하였다. 이어 16개 dataset-model 묶음마다 사례 기하평균을 계산하고, 이 16개 묶음값을 동일 가중치로 10,000회 복원추출(seed=20260824)하여 percentile 95% 신뢰구간을 산출하였다. 그 결과 비율은 1.000540931233, 95% 신뢰구간은 [0.999967474766, 1.001121781209]였으며 1을 포함하므로 속도 우월성을 주장하지 않는다.

[재현성 부록 추가]
암호화 후보 평가 한 번은 한 실행 구성을 구성 선택 입력 전체에 대해 서로 새로 생성한 세 CKKS context/key set으로 수행한 묶음이다. 입력별 암호화 실행 수와 key run 수는 이 후보 평가 묶음 수와 구분하였다. 별도 입력 재평가는 선택 구성을 변경하지 않고 fresh context에서 수행했으나, 결과 파일에는 key fingerprint나 저수준 난수 seed가 기록되지 않아 난수 스트림 독립성 자체는 소스 외부에서 재검증할 수 없다.
