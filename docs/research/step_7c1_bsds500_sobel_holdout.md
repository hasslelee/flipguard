# Step 7C.1 BSDS500 Sobel Non-Tabular Holdout

Status: `PREDECLARED_NOT_EVALUATED` on 2026-07-30. The source and derived
artifacts replay byte-identically, and the static synthesis plan is feasible.
No encrypted result is claimed by this document.

## Research purpose

The primary FlipGuard evaluation is scalar-tabular. The completed
`mlp_square_poly3` extension changes graph depth but not input modality. This
extension asks a narrower non-tabular question:

> Can the frozen synthesis, security, bounded-repair, first-SAFE, and locked
> audit rules be applied without retuning to a thresholded Sobel
> gradient-energy graph over patches extracted from real natural images?

This is not a full edge-detector benchmark. It does not evaluate
non-maximum suppression, human boundary accuracy, packed image execution,
rotations, CNNs, or arbitrary graphs.

## Primary source and split roles

The source is the official
[BSDS500 release](https://www2.eecs.berkeley.edu/Research/Projects/CS/vision/grouping/resources.html).
The Berkeley release contains 200 train, 100 validation, and 200 test natural
images and explicitly requires tuning on train/validation before one fixed
test evaluation.

FlipGuard preserves those roles:

- train: threshold calibration only;
- validation: configuration validation and encrypted candidate selection;
- test: locked audit with no synthesis, repair, or retuning.

## Frozen extraction

Extraction policy:

```text
ID: bsds500_sobel_patch_extraction_v1
SHA-256:
07c196374cea947c5bd9d8d478311e75ba4754f875c4f19ce0387241d55da699
```

Images are ranked by a domain-separated SHA-256 key. Patch centers are
generated by a second domain-separated SHA-256 stream without replacement.
RGB pixels are converted with the exact normalized integer BT.601 formula:

```text
(299*R + 587*G + 114*B) / 255000
```

The sample budget is deliberately clustered by image:

| Role | Images | Patches per image | Patch observations |
|---|---:|---:|---:|
| Train threshold calibration | 100 | 8 | 800 |
| Configuration validation | 50 | 8 | 400 |
| Locked audit test | 50 | 8 | 400 |

Fifty image clusters per evaluated partition provide materially broader input
diversity than the old 10/7 synthetic Sobel/Harris probes while keeping the
fresh-key encrypted cost bounded. The 400 patches are not treated as 400
independent statistical samples; summaries must retain image clustering.

The application threshold is the nearest-rank 80th percentile of the 800
train-only Sobel scores:

```text
threshold = 0.19382021437908492
```

Validation contains 87 positive and 313 negative decisions. Audit contains
88 positive and 312 negative decisions. Validation and audit share neither
row IDs nor image IDs.

## Graph and policy boundary

The graph computes:

```text
Gx = -p00 + p02 - 2*p10 + 2*p12 - p20 + p22
Gy = -p00 - 2*p01 - p02 + p20 + 2*p21 + p22
score = Gx^2 + Gy^2
decision = score >= threshold
```

The adapter ID is:

```text
bsds500_sobel_rescale_graph_adapter_v1
```

It uses explicit `Pow2 -> relinearize -> rescale` nodes so the graph trace
matches the Lattigo evaluator. The graph has multiplicative depth 1, one
rescale layer, and no rotations.

Direct Policy V2 remains byte-identical:

```text
sha256:503240fbf1f0bb1c43c8ed216ae6360771cc3b23ff4224efa84926f470646603
```

`sobel_edge_score` is not inserted into the V2 supported-model lookup. The
artifact records this as a predeclared graph-adapter extension that reuses the
frozen alpha, margin floor, scale/prime guards, repair steps, four-trial
budget, first-SAFE rule, and Security V2 gate. This prevents the extension
from silently expanding the already frozen primary policy claim.

The configuration-validation contract has:

| Property | Value |
|---|---:|
| Samples / certifiable / ambiguous | 400 / 400 / 0 |
| Protected margin | 0.005081887058823592 |
| Alpha-margin error budget | 0.002540943529411796 |
| Initial candidate | `N13 / Q4 / scale19` |
| Initial candidate logQ / logP / logQP | 83 / 30 / 113 |
| Security V2 cap / headroom | 214 / 101 bits |

Static feasibility is not encrypted decision-integrity evidence.

## Encrypted protocol

Selection executes at most four candidate literals. Each trial evaluates all
400 validation patches under three fresh keys. Numerical rejection increases
scale primes by the frozen four-bit step; a level failure adds one Q prime,
with the frozen two-level repair bound. Selection stops at the first SAFE
candidate or returns NO_SAFE.

The locked audit:

1. verifies the selection plan, repair chain, trial ledger, candidate literal,
   model, source archive, extraction policy, and partition digests;
2. confirms validation/audit row and image disjointness;
3. evaluates the byte-identical selected literal on all 400 test patches with
   three new keys;
4. never calls synthesis or repair;
5. preserves REJECTED, FAILED, or ambiguous results without retuning.

An audit PASS supports only the declared Sobel patch graph and BSDS500
extraction scope. An audit negative result is retained and lowers the claim.
